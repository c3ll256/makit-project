# 宠物机单面贴装混拼板

> 旧版双板方案。当前产品采用主控集成、彩屏直插的单主板；本设计的加工资料仅对应旧版。

66×60×1.0mm、双层FR4、1oz；每张主载板52.5×54.5mm一块、屏幕转接板20×11mm一块。仅生产顶面回流贴装，两种GH连接器均朝上。

## 拼板与分板

主载板实例平移(-5,-13)mm，转接板实例平移(-13,8)mm，平面内均不旋转。转接板以整块绕Y翻面的制造坐标定义：GH在生产top，屏幕方孔排母在生产bottom。矩形板边不变；16个信号/固定焊盘逐针与原设计比较，X反向、Y保持、层互换，最大数值偏差小于1e-12mm。编译器执行供应商封装的镜像，没有重绘焊盘或调换网络。

两款网络独立，生产板无跨板电连接。铣槽2mm，主板4处、转接板2处连接桥；每桥两端各5个Ø0.6mm非金属邮票孔，孔距1mm，共60个。外围3个Ø3mm非金属工艺孔，保留主板2个Ø2.4mm固定孔。剪桥分板并磨平残留，不扭掰已焊连接器。分板装机时把转接板翻回，使方孔排母朝向屏幕、GH位于屏幕背面且线缆出口保持原位置。

## 单面贴装与后装件

两只 JST GH 分别为 C378970（载板顶插）和 C495552（转接板侧插）。载板同时贴数字麦克风、单声道功放和 17 个配套阻容。工厂另贴一只 Molex 53261-0271 喇叭板座。分板后将华龙 HDK-151108ZA-5C6 自带的两针插头插入 SPK1。

贴装前不安装穿孔件。3颗穿孔按键、XIAO低矮排母、屏幕方孔排母另行焊接；XIAO针脚及模块后装。屏幕排母从生产bottom插入。所有穿孔焊尾及锡尖修至所在板底≤0.6mm，勿剪伤焊点；屏幕原厂方针露出段修到2.5mm并去毛刺。两端150mm GH7P线仍1对1连接。

## 本地贴装核验

供应商记录references/suppliers/c378970/part.json和c495552/part.json确认准确MPN、SMD、7P、1.25mm及Extended。JST GH图册（对应PDF第1、2页）核对顶插/侧插、信号焊盘和两侧固定焊脚，无定位钻孔要求。精确供应商封装保留；每只7个0.6×1.7mm信号焊盘加2个固定脚，最终最小异网焊盘间距0.6499mm。主板GND/pin1在+X；翻面后的转接板GND/pin1也在生产+X。连接器原点、针号、安装面、配合方向、封装镜像与CPL角度已对照实测和正反面预览。assembly.jlc_smt_verified只表示这些本地检查完成；下单网站实物模型的贴装预览还要核对。

## 验证与加工包

当前加工版本为 d574d2eb。主载板构建为 c6ecf1fe，屏幕转接板沿用 c518232e。两层 FR4、铜厚 1 oz、成品板厚 1.0 mm，拼板尺寸 66 × 60 mm。每张各含一块主载板和一块屏幕转接板。加工、顶面贴装和机械资料均已生成。最终检查为零错误、零未连接，另有非阻断的丝印与库封装提示。

工厂顶面贴装 22 件，共 13 种料号。每套另配一只带线插头的喇叭。SPK1 与七针屏幕插座分别配合各自的线束。

## 外壳兼容与制作

喇叭置于后壳左侧，麦克风顶部声孔经柔性导声件对准右侧壁。机身维持 22 mm，三键、屏幕及 USB 位置保留。喇叭开合路径与新增器件包络已单独检查，生产版载板与整机的最终三维装配检查尚待完成。
