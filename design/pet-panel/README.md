# 宠物机一套混拼板

用户选择主载板与屏幕转接板混拼于同一张生产板，分板后装配。成品生产板66×60mm，每张包含主载板52.5×45.5mm一块、屏幕转接板20×11mm一块。共同双层FR4、1.0mm、1oz为工程默认；不能沿用原1.6/0.8mm两种板厚。

## 拼板与分板

从两款已检查的冻结子板构建生成整板，保留原铜线、孔位、元件位置和针序。主载板实例平移(-5,-10)mm，转接板实例平移(-13,8)mm，均不旋转，坐标原点为整板中心。两款网络独立命名，生产板上没有跨板电连接；装机时通过150mm GH7P线缆连接。

铣槽2mm，主板4处、转接板2处连接桥。每桥两端各5个Ø0.6mm非金属孔，孔距1mm，共60个邮票孔；外围另有3个Ø3mm非金属工艺孔。两款原板的2个Ø2.4mm固定孔保留。先剪桥分板并把残留磨平至原成品轮廓，再装配；避免扭掰已焊连接器的板。

交给板厂时说明两款设计、每张各1块、双层FR4、1.0mm、1oz、2mm铣槽加邮票孔。该包自身已是一套混拼，不再要求代拼相同阵列。附加费与工艺接受以板厂订单审核为准。

## 外壳与焊接

当前外壳已接入两款1.0mm子板的发布装配模型。主板支撑提高0.6mm、转接板支撑降低0.2mm，保留元件顶面、插座配合面、USB及按钮高度；背面GH座与后壳最小间隙0.55mm（网格0.02mm）。无未声明硬干涉，前组件退出26mm（步长0.25mm）及按钮0.25mm行程（步长0.05mm）均无硬件重叠。

GH细脚需锡膏回流或熟练手焊，焊牢定位脚、检查无锡桥。两款板的所有穿孔焊尾与锡尖（含XIAO低矮排母）均修至板底≤0.6mm；屏幕原厂方针露出段修到2.5mm并去毛刺。分板后再装入已适配的外壳，避免残余桥耳占用支撑间隙。
