# XIAO ESP32S3 宠物机单载板

载板外廓 68.50 × 48.25 mm，双层 FR4，厚 1.0 mm。左下延伸区承载三键，外侧给扬声器和后壳螺柱留出位置。大键 SW_LEFT、最下方小键 SW_MID 和内侧小键 SW_RIGHT 分别对应 D7、D9 和 D3。右下角保留半径 3.65 mm 的螺柱避让槽，两端以半径 1.5 mm 圆弧过渡。载板通过两颗 M2 螺钉独立固定。

XIAO 从上方插入原有两排插座，自带 USB-C 对准原右侧开口。1.54 寸八针彩屏装在中部 2.54 mm 单排母座，7 脚 CS 接地，8 脚 BLK 接 D6，GND 靠右、BLK 靠左。屏幕扫描方向相对卖家图片旋转 180°。左侧 SPK1 接带原厂两针插头的喇叭，红线至 1 脚，黑线至 2 脚。顶面 MIC1 的进声孔经独立 TPU 弯管对准右侧进声口。

## 制作与装配

载板下表面 Z3.74，元件面 Z4.74。后焊通孔引脚含焊点修整至板下不超过 0.60 mm。先插线并整理喇叭余线。电池固定在载板空白区及齐平的后壳托面上，底部用 1 mm 泡棉，避免压迫软包。开关及屏座承受的按压力通过载板支点及压框传给外壳。实物首件核对屏针插入量、USB-C 正反插、收音和回放。
