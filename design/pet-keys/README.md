# 宠物机 XIAO / 7P TFT 载板

52.5×45.5 mm 异形双层FR4，1.6 mm、1 oz。三键轴心PCB坐标(-14.5,-2)、(0,-5)、(14.5,-2)，左右开关旋转-35/+35°；转换到壳体时Y减21.5。板边避让相邻闭壳螺柱，用户认可的外部键位与USB位置保持。

## 主控插接

两条XFCN MF254V-11-08-0540（C2915256）低矮圆孔排母，本体3 mm、2.54 mm节距、行距15.24 mm。近USB的七位接XIAO，第八位空置。每侧XIAO圆针使用MH254V-11-04-1000（C509261）+ MH254V-11-03-1000（C2844842），本体均3 mm，名义板间距6 mm；不得换8.5 mm高排母。

USB朝+X，A排在+Y，B排在-Y。A从USB端D0/D1/D2/D3/D4/D5/D6，第八位空；B为VBUS/GND/3V3/D10/D9/D8/D7，第八位空。左/中/右按键用D7/GPIO44、D9/GPIO8、D3/GPIO4，内部上拉、低有效，默认20 ms消抖。D0/D1/D2/VBUS及空位不接线路。

## 7P彩屏接口

用户选定优信电子1.3寸带铁框7P焊接ST7789模块，240×240、3.3 V；Grove接口已移除。J_LCD为HX PZ2.54-1x7P ZZ（C32713273），板正面竖直插接，壳体坐标(20.2,-13)、PCB旋转180°，1脚位于+X端。

|针号|屏幕功能|XIAO|
|---|---|---|
|1|GND|GND|
|2|VCC|3V3|
|3|SCL|D8 / GPIO7|
|4|SDA|D10 / GPIO9|
|5|RES|D4 / GPIO5|
|6|DC|D5 / GPIO6|
|7|BLK|D6 / GPIO43|

SCL/SDA为硬件SPI时钟和MOSI，无CS，屏幕独占SPI。BLK仅逻辑控制，按卖家说明低关、悬空开；固件采用开漏低电平关闭、释放开启，不用GPIO给背光供电。供电取XIAO 3.3 V，电池只接BAT+/BAT-。

配2.54 mm、1×7P、100 mm预压接母对母线，1对1至7对7。插前按功能标签核对，不凭插头朝向或颜色判断。屏幕端正面看GND在左，载板端1脚在右；不反接电源。母头按17.78×2.6×14 mm默认包络保留，用户无需逐线焊接。

## 制造与装配

板底壳体Z3.140，FR4顶4.650、铜层顶4.685、器件基准约4.735；XIAO板底10.735、USB中心Z13.1。先手焊三开关、7P排针、两条低矮排母；开关/7P背脚与锡尖修至板底≤0.6 mm，原排母尾脚约0.81 mm由后壳让位区容纳。先检查短路，再插XIAO圆针，USB端对1脚，第八位空置。

配套30 mm厚新前后壳及长杆帽。壳内载板为实际装配状态；旁边整板仅作同一块板的完整发布参考，不增加采购数量。首次试装核对屏幕和线头厚度、实际电池及打印压配。
