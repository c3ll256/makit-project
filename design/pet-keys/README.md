# 宠物机 XIAO / 7P TFT 载板

52.5×45.5 mm 异形双层FR4，1.0 mm、1 oz。三键轴心PCB坐标(-14.5,-2)、(0,-5)、(14.5,-2)，左右开关旋转-35/+35°；转换到壳体时Y减21.5。板边避让相邻闭壳螺柱，用户认可的外部键位与USB位置保持。

## 主控插接

两条XFCN MF254V-11-08-0540（C2915256）低矮圆孔排母，本体3 mm、2.54 mm节距、行距15.24 mm。近USB的七位接XIAO，第八位空置。每侧XIAO圆针使用MH254V-11-04-1000（C509261）+ MH254V-11-03-1000（C2844842），本体均3 mm，名义板间距6 mm；不得换8.5 mm高排母。

USB朝+X，A排在+Y，B排在-Y。A从USB端D0/D1/D2/D3/D4/D5/D6，第八位空；B为VBUS/GND/3V3/D10/D9/D8/D7，第八位空。左/中/右按键用D7/GPIO44、D9/GPIO8、D3/GPIO4，内部上拉、低有效，默认20 ms消抖。D0/D1/D2/VBUS及空位不接线路。

## 7P彩屏接口

J_LCD为JST BM07B-GHS-TBT(LF)(SN)(N)（C378970）竖插GH1.25mm7P，壳体(17,-12.5)，PCB(17,9)，旋转0°，1脚在+X侧。信号1–7为GND、3V3、D8、D10、D4、D5、D6。无CS，屏幕独占SPI；BLK仅逻辑控制，开漏低关/释放开。

20×11×1.0mm屏幕转接板正面方孔排母、背面GH侧插，150mm GH7P线两端1对1。GH锁扣座不能换普通杜邦头，不能混用SH/ZH。屏幕方针露出段修至2.5mm，插入排母3mm深插孔；无需拆焊排针。

## 固定与制造

两孔Ø2.4mm配M2×4盘头螺钉和1mm打印压垫，固定到后壳，按键载荷由独立支点承担。XIAO、USB和按键位置保持。所有穿孔焊尾与锡尖（含圆孔座）修至板底≤0.6mm，勿剪伤焊点。GH细脚手焊或锡膏回流，定位金属脚焊牢，放大检查无锡桥。
