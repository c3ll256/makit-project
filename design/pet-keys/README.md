# 宠物机三键与Grove承载板

用户选择制作三键小板并集成屏幕Grove，主控仍为XIAO ESP32-S3。59×26.5 mm外接尺寸、随云朵内腔收边，双层FR4、1.6 mm、1 oz。三颗开关朝正面，Grove横座在背面中央桥位；板边两处R3.6缺口让开合壳螺柱，2×Ø2.2无铜孔由后壳定位销定位。

## 元件与连接

- 三开关：K2-1102DP-C4SW-04，C110153，6×6×5 mm插装手焊。供应商编号1/2同组接KEY，3/4同组接GND，按下连通。使用KiCad标准5 mm机械模型，供应商原模型高度不符；电气封装仍为供应商封装。
- J_KEYS：保留C32713270四孔封装但不装排针，直接焊短线。1=GND，2=D0左键，3=D1中键，4=D3右键。XIAO内部上拉、按下为低、默认20 ms消抖。
- J_LCD_MCU：同样不装排针，1=GND，2=3V3，3=D10 DATA，4=D9 SCK。XIAO端仍可用朝板内弯排针/杜邦母头拆卸。八根短线直接焊PCB，避免竖排针加母插头超出22 mm壳厚。
- J_GROVE：Megastar ZX-HY2.0-4PWZ，C7429589，板背手焊，旋转180°朝+Y。板坐标(10,-5)。供应商引脚1=GND黑、2=3V3红、3=DATA白、4=SCK黄；屏幕官方J1编号反向（4=GND、3=VCC、2=DATA、1=SCK），按线色/功能配对。与Seeed NS-Tech NS-1125-W00008 Grove图纸的10 mm壳宽、2 mm节距、0.5 mm方针、3.5 mm键槽截面核对。
- 全部手工通孔焊接，无SMT代工需求。电源线宽0.5 mm；没有提高XIAO或屏幕的额定供电能力。

## 外壳配合

板坐标到外壳为Y-21.5；导出STEP原点偏移由CAD变换(-100,78.5,12.505)对齐。PCB模型板底12.505、铜层顶14.05，开关顶19.1 mm；生产名义板厚1.6 mm。三键中心为(-23.8157,-13.75)、(0,-27.5)、(23.8157,-13.75)，正面外观位置不变。定位孔板坐标(0,-11)、(-9,-9)；下方合壳螺柱坐标(±22.5,-21.7)，避让缺口以板坐标(±22.5,-0.2)为圆心。

前壳不再夹独立开关；后壳支撑承载整板，电池盘降边及线槽适配Grove。完整装配STEP已导入外壳，全部已建模硬件无实体碰撞；插头以记录的外露包络检查，柔性线仍按装配说明平铺。
