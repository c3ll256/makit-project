# 7针彩屏薄型锁扣转接板

> 旧版双板方案。当前产品采用主控集成、彩屏直插的单主板；本设计的加工资料仅对应旧版。

20×11×1.0mm双层FR4，1oz。正面HC-PM254-5.0H-1x7PZ（C27985232）5mm高方孔排母，插孔深3mm；保留优信1.3寸7P焊接模块，将原厂0.64mm方针露出段修到2.5mm并去毛刺。背面JST SM07B-GHS-TB(LF)(SN)（C495552）GH1.25mm7P侧插锁扣。150mm GHR-07V-S母壳预压接线，两端1对1至载板竖插GH座，端子SSHL-002T-P0.2。

从屏幕正面左至右为GND/VCC/SCL/SDA/RES/DC/BLK。方孔座1脚在-X侧；GH同功能编号1–7，原生供应商封装由编译器处理背面镜像，不手工改焊盘。屏幕针进入方孔座，转接板下方两块1mm泡棉压紧，防止脱离；排母焊尾修至板底≤0.6mm。
