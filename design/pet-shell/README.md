## 线束与电路

JST GH1.25mm7P、150mm预压接线，GHR-07V-S壳、SSHL-002T-P0.2端子，两端1对1；GH不同于SH/ZH/PicoBlade。原屏GND/VCC/SCL/SDA/RES/DC/BLK，通过转接板与GH依次到GND/3V3/D8/D10/D4/D5/D6。SCL/SDA是SPI，不是I2C，无CS；BLK只作逻辑控制，开漏低关/释放开。三键左中右D7/D9/D3，内部上拉。电池仅接BAT+/BAT-。

七条独立走线包络91.55–110.47mm，先错层避开XIAO，在压框下方经过，再由压框上沿外七条错位通道上升，外侧线路在更高处横跨，不在同一高度交叉。选150mm留弯曲和拆装余量，不能按渲染折线剪线；实际用柔顺圆弧、松弯，端子根部不压折。多余线在电池上方服务区约24×20×3mm（中心-6,3,10.5）平铺两层，以泡棉小胶片约束，勿夹接缝、碰键杆或绕紧螺柱。七根绝缘线Ø0.8为公开默认，GH母头为保守包络，实物仍须核对。

## 制造与装配

按用户选择，主载板与转接板混拼于66×60×1.0mm双层FR4、1oz生产板，每张各一块。2mm铣槽，主板4处、转接板2处桥，每桥两端各5个Ø0.6mm孔、孔距1mm，共60个邮票孔；另3个Ø3mm工艺孔。生产整套时采用pet-panel的当前加工包。先剪桥分板，将残留磨平至原成品轮廓再安装。主板支撑比原1.6mm方案提高0.6mm，转接板支撑比原0.8mm方案降低0.2mm；元件顶面、插座配合面、USB和按键高度保持。

外壳选透光PETG，深色屏框与浅色键帽保留；模型透明度是显示参数，不是材料透射率，实际效果以2mm壁厚首件为准。PETG、0.2mm层高。前壳正面朝下、后壳背面朝下；大圆角、挂绳球及局部悬空筋用选择性支撑，配合面尽量避支撑。压框、挡片和1mm压垫平放，边框正面朝下，按钮圆顶朝下、杆向上，必要时局部支撑。所有12个打印件各为单实体，最大72.508×81.621mm，适配180×180mm平台。先打一组压配试样、清理孔口与接缝，不锤击、不使用扭矩枪；收缩未经实物标定。

1. 载板焊好GH竖插座、三键及低矮排母；转接板焊正面方孔排母与背面GH侧插座。GH细脚需锡膏回流或熟练手焊，先焊定位脚，放大检查无锡桥，修短指定背脚。
2. XIAO焊圆针4+3位后插到底，USB端对1脚，第八位空。将载板放后壳，装两个打印压垫和两颗M2×4，轻拧到不晃。
3. 电池线焊BAT+/BAT-，用1mm底胶固定在托盘，不叠厚胶、不压电芯。保留引线余量。
4. 台面翻转前壳，装带防转键屏框、屏幕、四角1mm软垫及C形压框，均匀轻拧4颗M2×6。屏幕针尖修至2.5mm后接转接板；后壳软垫在闭合后防其松脱。
5. 装三帽、压入各挡片，确认自由滑动与回弹。贴XIAO屏蔽罩垫及两个转接板支点垫。
6. 两端GH插到底、锁扣卡住，按GND至BLK核对针序，轻拉插壳检查锁止，按模型通道铺线并固定余线。
7. 整组前壳沿Z下降，USB经后开通道就位，按键不预压卡住、线不夹缝。用原四颗M2×6沉头轻拧关闭。
8. 维修先断电、拆后壳螺钉，抬起后先释放GH锁扣再拉插壳，不拽线；保留载板固定螺钉。拆屏再松内部压框。
