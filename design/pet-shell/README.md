# 点子宠物机外壳

六瓣云朵掌上宠物机，约74×86×22 mm。用户确认半透明薰衣草蓝紫的圆润外形、深色圆形屏幕边框、三颗圆顶键和顶部挂绳球；USB-C采用用户认可的同色内收口及圆角凹口。

## 按钮布局

用户要求三颗按钮靠近。默认左右帽各内收3 mm、下移2 mm，中间帽上移1 mm；帽中心为(-20.8157,-15.75)、(0,-26.5)、(20.8157,-15.75) mm，直径仍为9/11/9 mm。相邻中心距23.428 mm，比原27.5 mm缩小14.81%；两侧跨度缩小6 mm。三颗帽的独立压装偏心推板对准已有开关。可调参数为button_inward_shift、button_side_drop和button_middle_raise。

## 内部结构

- 新版59×26.5 mm三键/Grove承载板位于屏幕后下方；板底基准Z=12.505，模型铜层顶14.05，开关顶19.1 mm。使用当前发布板的完整装配STEP；三颗开关位置固定，正面帽通过独立压装偏心推板传力。
- 原独立开关卡扣改为PCB支撑：左/中键下方圆柱、右键外缘承力台；两个Ø1.8定位销配板上Ø2.2孔。前壳两处上限位台保留约0.15–0.2 mm轴向活动量。按键帽由圆顶、Ø5.2导向杆和Ø3.2装配销构成；独立1.2 mm厚偏心推板从壳内压到销上，孔径3.05 mm（直径干涉0.15 mm），顶部有0.2 mm导入倒角，止口肩承担按压力。推板端部半径2.9 mm并作防脱法兰，在原开关顶面19.1 mm接触传力。前壳内侧胶囊形滑动腔为推板留每边0.3 mm余量，并预留0.25 mm工作行程，腔顶20.6 mm、外侧名义余壁1.4 mm。
- 后壳电池盘下半部降至9.5 mm，Grove插头通道局部降至7.2 mm；屏幕端出线槽降至7.8 mm。保留上方屏幕支撑并增加左侧支点。XIAO USB端支撑靠外移，给板底插头让位。
- 四颗M2后装沉头螺钉；上方中心(±27,13)，下方(±22.5,-21.7)。板边圆弧缺口半径3.6 mm避让螺柱。所有紧固件及螺柱来自打印螺丝接头套件；螺柱脚按曲面后壳内表面修边。
- J_KEYS和J_LCD_MCU直排针不装，短线直接焊到孔内。屏幕线束在XIAO端保留1×4弯排针及杜邦母头，弯排针朝板内，母头向+Y平躺在XIAO下面。先插线，再固定XIAO。按键四线接原接线定义。
- Grove插座位于板背中央偏右，朝+Y插入；线从电池上方通过，再由屏幕端上方接入。彩色曲线是直径0.8 mm四芯线的走线路径包络，约46.1 mm自由路线，不是线缆实长。多余线可平铺在电池上方24×24×1.6 mm空间（中心Y=-2,Z=8.7），不可堆在线束口或螺柱下。

## 来源及机械假设

- PCB来自当前发布版10610ae9f34a5d549de4894a0ba9dd48e061727f979d359917232642db5cb4de，按其板框、实体元件、焊脚、铜层和定位孔核对。
- 开关为C110153，供应商图纸5 mm高度；3D引用KiCad标准SW_PUSH_6mm_H5mm模型，来源和哈希保留在模型说明。供应商模型高度不符，不能用它决定帽杆长度。
- 屏幕40×40板及缺口、Grove位置来自官方Eagle文件；玻璃厚2、板厚1.6、Grove壳高6 mm仍为记录的默认值。XIAO21×17.8来自Seeed，板厚1.2、USB-C外伸1、高3.2 mm仍为默认。电池包络30×35×5；杜邦母头2.5×2.5×14为默认。
- 两端Grove插头以10.2×9×4.8 mm外露包络检查；不是供应商精确插头STEP。Grove板端插头最低到电池0.42 mm，到XIAO0.625 mm。线束最小净空：屏幕0.192、XIAO0.291、后壳0.367 mm。这些包络不能替代试装，也不保证所有加厚线头适用。
- USB凹口13.6×7.6，内通口10×4.3，同色收口面距插座0.35、厚1.2 mm；XIAO位置和USB开孔未改。

## 制造与装配

PETG，0.2 mm层高。前壳正面朝下、后壳背面朝下；大圆角贴床边、挂绳球及局部悬空筋使用少量支撑。边框正面朝下、按键圆顶朝下；三块推板以平底接触打印床，导入倒角朝上，清理孔边后再装。最大打印件约74.1×85.6 mm，180×180 mm平台足够。首次先清理小孔、插座通道和支撑残留，检查按键能自由回弹。

1. 手焊三开关、Grove插座和两组短线；J_KEYS/J_LCD_MCU不装直排针。检查焊脚不超过机械模型包络，线根低于PCB底面且避免压在支撑上。
2. 从前壳外侧插入三个按键帽；翻转前壳，从背面把对应推板沿开放通道压到帽销上，压到止口肩即可，勿锤击。推板长端分别朝对应开关，作为壳内防脱挡片。再放入边框、屏幕和焊好的按键板，推板远端平面落在开关按杆顶面，将板放入前壳两处上限位。
3. 在后壳盘内用薄胶固定电池；先把四个母头插上向内弯的XIAO排针，再固定XIAO。支撑面与板直接接触，不要额外垫1 mm厚胶抬高板或USB；胶用在侧边留位，不覆盖支撑面。
4. 插上Grove双头线，按彩色路径平铺，长线的余量平铺在电池上方预留区；合盖时对齐两个PCB定位销、XIAO支撑及接缝唇边。最后拧4×M2×6黑色沉头螺钉（ISO7046），在PETG自成形，不要拧过紧。

## 验证

整机无未声明碰撞；三组帽销/推板各有0.075 mm径向压配，已声明为设计配合，不作为误碰；前、后壳和每个打印件均为单实体。两端Grove插头及余线区与硬件无碰撞（连接面接触除外，线束在其插头和预留区内属于预期）。PCB对前壳净空0.235 mm，PCB对屏幕0.416，PCB对XIAO1.005 mm。按键帽向内0.25 mm路径无壳体/边框碰撞，最小0.2 mm；后壳退出20 mm路径无碰撞，其反向为合盖路径。路径和间隙以0.02 mm弦差网格测量，按键步长0.05、合盖步长0.25 mm。打印件尺寸、偏心按键的手感/导向配合和软线摆放仍需实物首装确认。电路板没有改动，继续使用发布版机械模型。前壳、三颗按键帽和三块推板需要采用聚拢版本配套制作。推板向背面退出20 mm路径通过（网格弦差0.02 mm、步长0.1 mm），最小净空约0.136 mm；电路板向背面退出20 mm无碰撞。压装孔的0.15 mm直径干涉为PETG默认，未实物标定，首件请先试一组配合，可调整pusher_socket_diametral_interference。
