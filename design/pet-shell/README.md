# 点子宠物机外壳

约74×86×30 mm六瓣柔和云朵，半透明薰衣草蓝紫PETG、深色圆形屏框、三颗圆顶肉垫按键及挂绳球。正面轮廓和键位遵循用户图；USB保持右侧同色内收圆角凹口。

## 使用与外观

手持电子宠物，正面屏幕与三键，背面四颗沉头螺钉，右侧充电。左右键中心(±14.5,-23.5)、中键(0,-26.5) mm，直径9/11/9 mm，外部键位保留。默认厚度30 mm容纳已焊排针屏幕与普通14 mm母线头；屏幕中心上移1.3 mm至Y4.3。旧22 mm壳与旧短帽不能直接沿用。

## 线束与装配路径

使用2.54 mm、1×7P、100 mm预压接母对母线，逐脚按功能核对1到1、7到7。七条路径包络长约68–88 mm，余线平铺电池上方24×22×4 mm服务空间（中心-6,3,12），避开螺柱、键杆和接缝。彩线是走线示意，不能照模型长度剪预制线；可以轻柔弯线，不压折端子根部。

前壳、屏幕、显示端母头、按钮和挡片作为一组向+Z退出26 mm，网格0.02 mm、步长0.25 mm，未测得重叠；反向为合盖。柔性导线随合盖重新铺放，不作为同一刚体移动。三键下压0.25 mm，步长0.05 mm无壳体/线束干涉，最小导向间隙0.2 mm；开关内部弹性压缩不按刚体相交判错。

## 制造与装配

PETG、0.2 mm层高。前壳正面朝下、后壳背面朝下；外大圆角、挂绳球和局部悬空筋使用选择性支撑，避开配合面。边框正面朝下；帽圆顶朝下、杆向上，必要时局部支撑；挡片平放、倒角朝上。所有打印件单实体，最大约74.1×85.6 mm，均适配180×180 mm平台。清理孔、线槽和接缝。先试一组0.15 mm直径压配，勿锤击，必要时调整挡片干涉参数；打印收缩未经首件标定。

1. 手焊三开关、7P排针与两条低矮排母，修短开关/7P背脚≤0.6 mm，排母原脚约0.81 mm可保留；检查焊点无短路、无锡尖。
2. XIAO焊好3 mm圆针后插入，USB端对1脚，第八位留空。电池线焊BAT+/BAT-，载板放入后壳支撑与定位销。
3. 电池用1 mm胶垫固定在托盘，轻铺电池引线；不要垫高或挤压电池。
4. 台面预装前壳：装边框和屏幕，帽从正面插入，背面压入挡片，确认长杆自由滑动。
5. 接两端7P线，逐脚核对GND到BLK，余线平铺电池上方；整组沿+Z反向竖直合盖，让USB经后开通道就位。
6. 确认三键回弹、线束不夹接缝，轻拧4×M2×6。拆卸断电后反向操作。
