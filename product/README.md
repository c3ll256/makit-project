# 点子宠物机

按2026-11-12用户照片采用紧凑、近圆的六瓣云朵外形，瓣间浅凹、外缘圆滑；深色圆屏框适度缩小，默认外径45mm；保持紧凑的正面比例。侧边按侧视绿线标记改为向前后面连续收拢的大范围圆弧坡面。前后壳及一体挂绳球均为半透明蓝紫PETG，搭配三颗圆顶肉垫键；中间按钮放大，默认三键直径9/13/9mm，中心位置保留。沿用蓝紫色作为默认配色，模型不透明度默认0.50（0为全透明，1为不透明）；选择透光PETG，实际透光程度以同壁厚首件为准。用户要求整机变薄并且牢固、不要松垮。当前默认机身72.508×81.621×22mm，含按键最大厚度23.4mm；云朵轮廓按参考图收浅并缩短，绿色标记键位、XIAO与USB位置保留。

## 平台与屏幕

Seeed Studio XIAO ESP32-S3（seeed/xiao-esp32s3）直接插入自制载板。两排3mm低矮圆孔排母MF254V-11-08-0540（C2915256），配每侧3mm圆针4+3位，第八个插座孔空置；不得换8.5mm普通排母或把方针插进圆孔座。

保留用户选定优信电子「1.3寸TFT彩屏模块(带铁框)_7P焊接」，ST7789、240×240 IPS、3.3V、无按键、无CS。屏幕PCB27.78×39.22、显示区23.4×23.4mm；事实依据用户卖家图片，未用相似屏替代。PCB1.6、LCM2.0、原排针本体2.5mm为明确工程默认，卖家未给整体厚度。

## 薄型七针插接

载板J_LCD采用JST BM07B-GHS-TBT(LF)(SN)(N)（C378970）竖插锁扣，壳体中心(17,-12.5)。屏幕后增加20×11×1.0mm双层转接板，正面HC-PM254-5.0H-1x7PZ（C27985232）方孔排母，本体5mm、插孔深3mm，背面JST SM07B-GHS-TB(LF)(SN)（C495552）侧插锁扣。

屏幕保留原厂焊接排针，将露出的针尖修到2.5mm，去毛刺后插到底；不拆焊、不顶到插孔底。转接板排母焊尾修至板底≤0.6mm，不能剪伤焊点。配JST GH1.25mm7P预压接150mm线，GHR-07V-S壳、SSHL-002T-P0.2端子，两端1对1。GH不是SH、ZH或PicoBlade，按针号核对GND和3V3再接电池。主板端从+Z插，转接板端沿Y插，锁扣完全卡住后轻拉插壳检查。

## 固定与手感

- 载板用2颗ISO7045 M2×4内藏盘头螺钉及2个1mm打印压垫固定，Ø2.4通孔，按键力由后壳支点承受；XIAO屏蔽罩上小块1mm软垫预压约0.2mm，防止模块翘起。
- 屏幕用4颗ISO7045 M2×6内藏盘头螺钉锁住C形压框，1mm泡棉在PCB角部压缩约0.2mm；支撑PCB和金属框，不压玻璃。屏框直径45mm，增加防转键，径向间隙0.2mm；屏幕定位筋与屏框一体连接，前壳留出圆框法兰台阶。
- 转接板底部2个软垫支点压缩约0.2mm，保持方孔座插合；7针线两端GH正锁止。余线在电池上方24×20×3mm服务空腔平铺并用泡棉胶小片约束，避开按键、螺柱、接缝。
- 电池503035约500mAh，30×35×5mm，中心(-8.6,1.0)，底Z3.1，下方1mm双面泡棉固定；不压电池、不叠额外厚胶。
- 三键外中心(-14.5,-23.5)、(0,-26.5)、(14.5,-23.5)mm，Ø9/13/9；导杆Ø5.2、导孔Ø5.8，工作行程0.25mm。挡片Ø3.05孔压到Ø3.2销，直径干涉0.15mm，保留自由回弹。
- 后壳4颗ISO7046 M2×6沉头螺钉，原中心(±27,13)、(±24,-20)保留。

## 电路与制作

主载板与屏幕转接板按用户选择混拼在同一张生产板上，分板后装配。共同板厚默认1.0mm，兼顾屏幕后方净空与受支撑的主板；拼板默认每张各1块，66×60mm，铣槽加邮票孔连接。保持元件上表面和插座配合面，主板下支撑提高0.6mm、转接板下支撑降低0.2mm；下单采用一套混拼加工包，分板后安装，清除邮票孔残留凸起。

屏幕GND/VCC/SCL/SDA/RES/DC/BLK对应GND/3V3/D8(GPIO7)/D10(GPIO9)/D4(GPIO5)/D5(GPIO6)/D6(GPIO43)，独占SPI、无CS。BLK低电平关闭、开漏释放开启，只作逻辑控制。按键左/中/右D7(GPIO44)/D9(GPIO8)/D3(GPIO4)，内部上拉、按下接地、默认20ms消抖。XIAO引脚依据官方 https://raw.githubusercontent.com/espressif/arduino-esp32/master/variants/XIAO_ESP32S3/pins_arduino.h 。电池仅接BAT+/BAT-，USB-C充电烧录。

载板52.5×45.5×1.0mm双层FR4、1oz；转接板20×11×1.0mm双层FR4、1oz。混拼生产板仅做顶面单面贴装，两种GH座都朝上并由工厂贴装回流；转接板整块翻面定义生产顶面，分板装机时翻回，使GH仍背向屏幕、方孔排母朝向屏幕。按键、排母和主控模块另行焊接/插装。两种GH座均在清单中，不能混成同款。载板和转接板的所有穿孔焊尾及锡尖（含低矮XIAO排母）均修至板底≤0.6mm，勿剪伤焊点。

PETG默认0.2mm层高。前壳正面朝下、后壳背面朝下，局部悬空结构选择性支撑；压框、挡片和压垫平放，边框正面朝下，按钮杆朝上。先试压配及配合面，去毛刺后装配；轻拧螺钉，不用扭矩枪。模型全为单实体打印件，适配180×180mm打印平台。
