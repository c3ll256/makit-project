# 点子宠物机

一只握在手心里的电子宠物机：六瓣柔和云朵，蓝紫半透明 PETG，正面方形彩屏、深色圆框、三颗圆顶肉垫按键，顶部挂绳球，侧面 USB-C 充电与烧录。用户认可的正面轮廓与按键布局保留。

## 平台与屏幕

主控采用 Seeed Studio XIAO ESP32-S3（seeed/xiao-esp32s3），约21×17.8 mm，带USB-C与锂电充电功能；用户要求直接插到自制载板。小型自制板承载三键、两排XIAO插座和屏幕接口，替代逐键飞线，用户已选择此方案。

屏幕采用用户选定的优信电子「1.3寸TFT彩屏模块(带铁框)_7P焊接」：ST7789、240×240彩色IPS、3.3 V、无按键。模块不在现有板卡索引，身份与机械事实依据用户提供的卖家图片，不用相似模块代替。

用户选择把原Grove屏幕插座改为单组7针插接线。载板使用HX PZ2.54-1x7P ZZ（C32713273）直排针，配2.54 mm、1×7P、100 mm、预压接母对母线；按两端功能标签逐一对应，不能反插或错一格。

## 用户需求

- 六瓣云朵与屏幕上、三键下的布局；三键按用户绿色标记，左右中心(±14.5,-23.5)、中间(0,-26.5) mm，直径9/11/9 mm。
- XIAO直接插到载板，屏幕通过7针线插接。
- 原同色内收圆角USB开口与XIAO位置保持。
- 内置单节锂电池，FDM两半外壳，背面四颗沉头螺钉。

## 工程默认

- 约74×86×30 mm，高度含挂绳球。30 mm厚度容纳屏幕自带直排针、14 mm母线头与载板端弯线空间。屏幕中心上移1.3 mm到Y4.3；按钮XY与USB位置保持。
- 电池503035约500 mAh、30×35×5 mm，托盘中心(-8.6,1.5)，底Z2.1；薄胶固定，不挤压电池。
- 三颗K2-1102DP-C4SW-04，6×6×5 mm，长直顶杆与压装挡片配套。
- XIAO两侧各焊3 mm本体圆针（4+3位），插入3 mm低矮圆孔排母MF254V-11-08-0540，每排第八位空置；禁止以8.5 mm普通排母替代。
- 不加蜂鸣器；PETG默认0.2 mm层高。

## 资料与尺寸

上传前缀20261110T152829794Z的商品图确定1.3寸带铁框7P焊接版本；参数表只采用1.3寸列，尺寸图只采用上半部。PCB 27.78×39.22 mm、显示区23.4×23.4 mm。正面从左到右GND/VCC/SCL/SDA/RES/DC/BLK，2.54 mm间距。SCL/SDA是SPI时钟和MOSI，1.3寸无CS。BLK按卖家说明悬空开启、拉低关闭。

卖家未给模块总厚度：默认PCB1.6、正面LCM2.0 mm；直排针本体2.5、露针6 mm；母线头包络17.78×2.6×14 mm。安装孔Ø2、距边2.5 mm按读图/默认，定位依靠板边而非孔。外壳为这些明确预留尺寸设计，首次试装核对实际模块和线头。

XIAO引脚依据官方 https://raw.githubusercontent.com/espressif/arduino-esp32/master/variants/XIAO_ESP32S3/pins_arduino.h 。载板7P排针尺寸依据供应商C32713273图纸第1页。

## 电路与装配约束

屏幕GND→GND、VCC→3V3、SCL→D8/GPIO7、SDA→D10/GPIO9、RES→D4/GPIO5、DC→D5/GPIO6、BLK→D6/GPIO43。无CS，独占SPI总线。BLK仅作逻辑控制，低电平关、开漏释放开启，不用GPIO给背光供电。按键左/中/右为D7/GPIO44、D9/GPIO8、D3/GPIO4，内部上拉，按下接地；不使用D2启动配置脚。

载板52.5×45.5 mm、双层1.6 mm FR4、1 oz铜，XIAO焊圆针后直接插入，USB端对插座1脚。开关与屏幕7P排针背焊脚和锡尖修至板底≤0.6 mm；低矮排母原脚伸出约0.81 mm，可保留在后壳让位区。屏幕线采用已压接母对母，不需要逐线焊接；电池BAT+/BAT-仍需焊到XIAO。屏幕线余量平铺在电池上方的空腔，避开按键、螺柱和接缝。

屏幕约¥10–30、接口与短线¥3–15、少量载板重制¥30–100、约4–10天，均为经验估计，非供应商报价。
