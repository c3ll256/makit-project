# 优信电子 1.3寸 TFT 7P 适配依据

选定「1.3寸TFT彩屏模块(带铁框)_7P焊接」，用户上传前缀20261110T152829794Z。参数表1.3寸列：ST7789、240×240、3.3 V、SPI、7Pin、PCB27.78×39.22 mm、显示23.4方形。尺寸图只使用上半部，下面1.44寸无关。无CS；SCL/SDA是SPI信号。

用户选择以7针插接替代原Grove。7P排针及预压接母对母线按GND/VCC/SCL/SDA/RES/DC/BLK逐一对应。PCB及装配包已更新，屏幕电路见载板说明和接线文件。

模块厚度未给出，采用PCB1.6+正面LCM2.0 mm，排针本体2.5/露针6，母头17.78×2.6×14 mm的明确默认。机壳厚度30 mm为这些线头留弯线空间；屏幕中心Y4.3、板底Z23.3，显示端母头底Z6.8；载板端母头顶Z21.235。电池中心(-8.6,1.5)，1 mm胶垫后底Z3.1。

网格公差0.02 mm：电池对屏幕母头0.53 mm、载板对电池1.1 mm；线束对前壳约0.19 mm，对后壳约0.35 mm，对屏幕0.6 mm。屏幕尺寸图不构成总厚度实测，首次试装核对实际模块与线头。

七条最短示意走线路径约68–88 mm，100 mm预压接线的余量平铺在电池上方，默认服务空间24×22×4 mm，中心(-6,3,12)已以只读探针核对避开硬件。彩线是路径包络，不是剪线长度。七线相互交叠体积逐对检查为0。

前壳连同屏幕、显示端线头和按钮组向+Z退出26 mm无重叠，采样步长0.25 mm；三键下压0.25 mm无重叠，采样步长0.05 mm。导线柔性变形未当作刚体路径验证。只保留帽/挡片的三组0.15 mm直径压配。
